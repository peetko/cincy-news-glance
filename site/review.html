    How fixes work

    Looks right hides a story from this list on this computer.

    Fix builds a rule: pick what's wrong, click the word that proves it, and send. It opens a GitHub issue; click Create.

    GitHub then tests the rule against every saved case and this morning's articles. If it fixes only this story, it goes live on the next update. If it changes other stories too, you get a pull request to look over. If it breaks something, nothing changes and the issue says why.
